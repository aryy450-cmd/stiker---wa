# Stiker WA - Hapus Background Online

Aplikasi Streamlit buat bikin stiker WhatsApp. Upload gambar > background auto hilang > download PNG transparan.

## Cara Pakai
1. Upload gambar JPG/PNG
2. Klik "Hapus Background + Jadiin Stiker" 
3. Download hasil PNG nya
4. Kirim ke WA jadi stiker

## Tech Stack
- Streamlit
- rembg - AI hapus background
- Pillow, OpenCV
